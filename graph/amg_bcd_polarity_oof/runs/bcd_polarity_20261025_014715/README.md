# B/C/D 图证据混用与极性损失实验

B=训练50%概率加图、无极性损失；C=全量加图、有极性损失；D=训练50%概率加图、有极性损失。C/D固定 lambda=0.1，未使用目标测试结果调参。复用旧D的紧凑图格式与门控，三组训练均用其Graph-OOF证据；原始音视频字幕、数据、学习率、每轮步数保持此前设置，不使用梯度检查点。三组各从最原始 checkpoint35 独立开始，每组5轮（36–40），共15权重。

训练集30755条，500条人工核验排除。源域极性伪标签30688条有效，67条待核验只跳过极性损失；原始生成训练仍使用全部样本。极性头读取Qwen最后一个提示词位置的隐藏表示，因果注意力不读取答案；分类头独立存储，推理仍用原始生成接口。

GPU0先C再D，GPU1训练B；每卡训练时只有一个进程。GPU1先结束后自动四路推理，GPU0训练队列结束后加入四路推理。15权重×MER2023(411)、SIMS(457)、OVMERDPlus(532)，45项、21000样本预测。按数据量降序，任务拆成至多64样本的互斥共享分片，尽量平衡两卡；所有推理均使用完整源图（不使用目标数据建图），并沿用相同紧凑格式与门控。旧D的随机20%整图/20%情绪丢弃由本次50%或100%保留设置替代，不重复叠加。

全部45项推理完成、所有推理进程退出、两卡显存释放后，自动启动每卡一个原版Qwen25测评进程。主指标MER2023 HIT、SIMS WAF/ACC、OVMERDPlus F_s/P_s/R_s。输出metrics_all.csv、per_checkpoint_summary.csv和RESULTS.md。

所有源代码、权重、日志及结果仅保存在服务器；不改写历史实验。

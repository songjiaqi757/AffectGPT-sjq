# 原188类图：H条件完成后的详细分析与采用决定

本报告基于本轮完整36项评分及CPU补充诊断。所有文件、计算和分析均在服务器；没有新增GPU推理、训练或改图。

## 结论

H没有成为优于C或P的统一方案。H保留原路径、仅删除显式Emotion列表；相对C和P均是7/9集点估计下降。保留原188类图和P复现基线，C继续作为主要研究候选，H作为负向/交互诊断保留，不升级为统一默认。不能据本轮宣布C已被独立验证为新最优，也不能宣布任何路径都无用。

九集混合指标均值：C 75.5485%，P 75.4293%，E 75.2496%，H 75.2147%。H-C=-0.3338pp，H-P=-0.2146pp。均值混合HIT/WAF/F_s，仅延续原汇总口径。

## 4. 各任务的实际含义

### SIMS：唯一相对C和P都上升的任务，但只多纠正1–2条

H WAF90.206%，C89.941%，P89.691%。H-C纠正1/伤害0；H-P纠正2/伤害0。C到H的正类召回85.71%→86.43%，负类92.34%不变。将neutral对非零参考计错的补充准确率也改善，但不替代官方WAF。正向证据样本很少，区间下界为0，不据此按SIMS测试结果设专用提示。

### SIMSv2、MOSEI：新增错误超过纠正

SIMSv2 H-C纠正7、伤害14；H-P纠正5、伤害12，净少7条正确。H-C正类召回相同，负类85.86%→84.43%，负类少7条正确。实际干预且有效计分的363条子集，WAF87.320%→85.403%，说明负向变化并非仅被全量汇总稀释后无法看见。
MOSEI H-C纠正23、伤害37，净少14；H-P纠正24、伤害34，净少10，正负类召回都下降。MOSI H比C多2条正确，但比P少1条，不能称H优于原P。

### 离散情绪：IEMOCAP修复了P的一部分，仍未超过C

IEMOCAP H-P HIT+0.443pp、M+0.790pp；H-C HIT-0.373pp、M-0.183pp。happy等类别恢复一部分，但sad HIT仍只有39.84%，低于P的40.41%；anger H54.71%也低于C56.35%。不能把相对P恢复解释为额外超过C。
MELD H相对C HIT-0.630pp，M37.487%→37.109%；disgust仍只有14.22%，未修复关键弱类。MER2024 H对angry有局部改善，同时happy/sad/surprise下降，总HIT下降。没有统一类别修复。

### OV：精确率、召回都未改善

C→H：F62.925→62.530，P61.704→61.337，R64.315→63.900。平均抽取情绪数3.434→3.436，删除列表没有自动使回答更精确或更简洁。H相对P也下降，不能将十类图上一轮OV局部信号移植到本次188类图。

## 5. 补齐单元后，对路径和列表的判断需要更新

无显式Emotion列表时，路径H-C的九集平均为-0.3338pp；有列表时，路径P-E为+0.1797pp。无路径时移除列表C-E为+0.2989pp；有路径时移除列表H-P却为-0.2146pp。
因此不能再把“列表是噪声，保留路径再删列表一定更好”当作统一解释。两个提示块有交互，效果依赖背景。交互(P-E)-(H-C)在8/9集为正；只有MER2024的名义区间完全高于0：+1.069pp，[+0.120,+2.070]。未多重校正，且该集来源聚类未确认，只作机制线索。
可能存在训练输入格式适配、词汇/候选集中度或其他提示块交互；当前未用格式/长度匹配的内容破坏对照分离这些因素，不能据此证明路径推理忠实。

## 6. H仍有情绪提示，响应也不是没有发生

4777条样本共保留9554条路径，其中8554条（89.53%）为Cue→Emotion，1000条为Cue→Appraisal→Emotion。原列表每条3个情绪；路径端点平均仍有1.860个不同情绪。H不是不含情绪信息的Appraisal条件。
H-C在2293/4777条（48.00%）改变原回答；H-P在2067/4777条（43.27%）改变。模型对干预有响应，但没有变成稳定净收益。
OV活跃子集的路径候选映射覆盖从C约59.75%到H约60.81%，而该子集F下降62.07%→61.08%。路径词采纳率不是正确性；参考外标签统计也不能直接当成人工确认的无依据情绪。

## 7. 净纠错和新增伤害案例

SIMSv2 aqgy5_0013_00019，参考-1，“别拿我的容忍，当成你们不要脸的资本”：P输出anger/frustration/confidence/determination，判positive；H输出anger/frustration/anxiety/stress，判negative。这是删除列表后的纠错。
SIMSv2 aqgy4_0001_00062，参考-0.8：C/P判negative，H增加self-importance/pride后判positive。H保留的两条路径末端都是anger，仍没阻止正向属性混入最终极性。因此“路径情绪负向”或“已删列表”都不能保证整体立场正确。
OV sample_00000361，参考concern/warning：P回答thoughtful/determined/responsible/anxious/overwhelmed；H删去后两项，只剩前三项，参考覆盖下降。这里的案例方向沿既定映射诊断，不是官方F的可加贡献。
MOSEI 208592_7，参考-1，“The only good thing … are the songs and dances”：C/E/P/H全部仍为positive/neutral。MOSI jUzDDGyPkXU_6对电影的批评，H也保持P的excitement/enthusiasm/passion混入。字段删除没有补上评价对象、only范围和整体推荐立场。
以上只读现有字幕、回答、参考和固定映射，没有新增完整音视频盲审，不将案例当作真实心理状态重标。

## 8. 下一步

1. 原图与P基线保留；C继续作为主要研究候选，H保留本次负向/交互结果，不扩训练、不改图、不扫新checkpoint。C均值最高仍不等于独立验证最优。
2. 下一项是Appraisal内容有效性：在来源隔离的开发材料上比较原C、Cue-only及格式/长度尽量匹配的状态打乱对照。冻结Cue、门控、权重和种子，只改变Appraisal内容。先统计打乱后实际改变的提示/维度比例：若原来已把某维全部状态列出，打乱可能成为零干预，不能拿它的无差异证明语义无用。
3. 本轮没有解决1253条开发候选的媒体和SIMS系列来源重叠，也没有重新作全盘开发数据寻址。先核实媒体可用性与来源隔离，再做确认性验证；当前九测试集不继续承担提示调参选择。
4. 语义证据重点仍是主体、当前/回忆时态、评价对象、否定/only/转折范围，人物情绪与整体推荐/批评立场分开表达。经开发材料验证净增益后，再考虑匹配训练对照。
5. 运行调度上，下次用整样本四条件为单位的动态任务队列；A100保持四进程GPU推理、主机模型和checkpoint加载串行，避免本次3781/996静态分配带来的空闲。这个调度问题影响耗时；本轮基线逐字复现及同卡核验支持比较口径不受影响。

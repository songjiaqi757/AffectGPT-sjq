# 用户授权的图证据续训实验

30/35/40/45/50五个原始checkpoint分别追加5轮，每轮5000迭代，batch=3。每卡一个独立进程，GPU0依次30/40/50，GPU1依次35/45。

本次训练成员30755条（原pseudo_train 27679 + pseudo_validation 3076）；人工核验500条（原gold_audit 300 + diagnostic_reserved 200），保留原角色与标注来源，不推断已完成任何人工标签。原Cue/图/P4的冻结版本不回写。

无独立验证集；不使用原验证成员进行新参数选择或选模。原图、Cue模型、查询参数冻结。当前微调实验使用工程Cue策略，人工可靠性和来源审计仍未完成。原始AffectGPTcheckpoint的历史训练暴露需单独核验，本次划分不能消除过去暴露。

训练恢复原checkpoint的模型、AdamW和GradScaler，学习率1e-5，不重启warmup。新增续训轮次严格为base+1至base+5。训练上下文上限2048，预留1536 prompt、510答案及BOS/EOS；图证据和字幕按固定预算压缩，不因答案长度改变输入。图分数为关联支持度，不能当概率、因果关系或最终标签。缺少证据时回退原始Prompt。

所有文件仅保存在服务器。
